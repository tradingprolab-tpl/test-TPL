# ¿Qué tipo de trader eres? — Williams Trader / Trading Pro Lab

Test web de 30 preguntas, 8 arquetipos y recomendación orientativa de estilo. Sin backend, sin dependencias.

## Archivos
- `index.html` → todo en uno (diseño, preguntas, textos y motor). Se abre con doble clic.
- `assets/arquetipos/` → aquí van tus imágenes (PNG). Nombres exactos:
  `francotirador.png`, `velocista.png`, `estratega.png`, `analista-eterno.png`,
  `apostador.png`, `vengador.png`, `prisionero-del-grafico.png`, `constructor.png`.
  Si la imagen existe, reemplaza sola el espacio reservado.

## Publicar en GitHub Pages
1. Sube TODO el contenido de esta carpeta a un repositorio.
2. Settings → Pages → Branch `main` → carpeta `/ (root)` → Save.
3. En `index.html`, busca `url: ''` y pon tu enlace público (ej. `https://usuario.github.io/repo/`).

## Editar
Busca `const RAW` (preguntas) y `const ARCH` / `const STY` (textos y colores). La leyenda de puntos está al inicio del bloque.

Test educativo y orientativo. No es asesoramiento financiero y no garantiza rentabilidad.
